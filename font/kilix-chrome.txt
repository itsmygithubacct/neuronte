# The symbols Kilix prints on its bars, for neuronte-kilix-chrome-v1: the
# tab's bell mark, the pane title bar's buttons and chips, the top bar's
# widget symbols and the weather symbols. Written for this project, each
# from its meaning alone. No font was read, and no glyph that another
# font has at these code points was looked at: the private-use code
# points are the numbers Kilix prints and nothing more.
#
# The grid and syntax of strokes.txt (see train/strokes.py): x 0..10 across
# the cell, y 0..20 down it. Each symbol fills the cell's width and sits
# about the middle of its height (y 10), in one colour, to be read at
# 10 x 20 pixels, where one grid unit is one pixel.
#
# A "# set NAME NETS" line starts a training set: the characters after it,
# in this order, are cut into NETS equal runs, one group net each. A
# character line with no strokes is made by train/kilix_chrome.py (the
# battery from its level or mark, a weather symbol from a sun, a cloud and
# what falls from it). A "# note U+XXXX text" line says what the symbol
# means in Kilix; the review sheet prints it.
