# ellipsis, as pixels. Written for this project. No font was read, and no width
# was copied. The regular face at this em is sheared on the grid, each row by
# (baseline - row) / 4 rounded to the nearest pixel, a tie away from zero, so
# the top sits to the right of the bottom. The advance is widened so the slant
# fits in the row. One character per block: the character (or U+XXXX), a space
# and its advance in pixels, then 18 rows from the ascender down, each starting
# at the pen. # is ink. train/glyphs.py makes each inked pixel a round dot
# joined to the inked pixel beside it and below, so the net's target is these
# pixels. The baseline is row 14 and the x-height row 5. In the drawn cell the
# baseline is row 24 below the pen (UI_TOP 10). The strokes are two pixels wide.
# Bold is the same letter struck twice, one pixel apart, by the drawer.
