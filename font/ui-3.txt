# Neuronte desktop face at an em of 3 pixels: printable ASCII and the
# ellipsis, as pixels. Written for this project. No font was read, and no
# width was copied. One character per block: the character (or U+XXXX), a
# space and its advance in pixels, then 3 rows from the ascender down,
# each starting at the pen. # is ink. train/glyphs.py makes each inked
# pixel a round dot joined to the inked pixel beside it and below, so the
# net's target is these pixels. The baseline is row 2 and the x-height
# row 1; in the drawn cell the baseline is row 4 below the pen
# (UI_TOP 2). The strokes of the nearest pixel face were refitted to
# this grid, one pixel wide. Bold is the same letter struck twice, one pixel apart,
# by the drawer.
