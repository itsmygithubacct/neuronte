# Neuronte

A character goes in, as ASCII or as UTF-8. The net writes that
character's pixels into a caller-owned buffer. Games, the OS, and
`soft-raster` link that library. The same buffer can be shown in a
Kilix terminal or in a GUI window.

Status: local only. No remote. Implementation has not started.

The research notes, the reference pins, and the lab measurements are in
`/home/pleb/research/projects/neuronte`.
