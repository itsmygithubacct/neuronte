# width was copied. One character per block: the character (or U+XXXX), a
# space and its advance in pixels, then 20 rows from the ascender down,
# each starting at the pen. # is ink. train/glyphs.py makes each inked
# pixel a round dot joined to the inked pixel beside it and below, so the
# net's target is these pixels. The baseline is row 16 and the x-height
# row 6; in the drawn cell the baseline is row 27 below the pen. The
# strokes of the first-pass face were fitted to this grid, two pixels
# wide. Bold is the same letter struck twice, one pixel apart, by the
