# Neuronte diacritic marks. Written for this project. No font was read.
# The same grid as strokes.txt: x 0..10, y 0..20, cap top 4, x-height 8,
# baseline 15. Each mark is keyed by its combining code point and drawn
# for a lowercase letter, centred on x 5. train/glyphs.py moves it to the
# letter's centre, and moves marks above up by 2.3 for a capital, which it
# shortens to make room. Marks below sit on the baseline for every letter.
