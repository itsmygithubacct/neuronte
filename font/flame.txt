# The Kilix flame, the mark of the Start button and the desktop icon. Drawn
# for this project from the desktop's own three polygons; no icon file was
# read or traced. Same syntax as font/icons.txt (see train/strokes.py),
# with its own palette, font/flame-palette.txt. Three layers, back to
# front: the red outer flame, the yellow middle, the white core. Each
# lower layer runs under the one above, so no seam shows.
#
# The teacher's 16 by 16 grid puts its vertices on pixel centres. A vertex
# (x, y) there is (0.625 * (x + 0.5), 5 + 0.625 * (y + 0.5)) here, so the
# mark fills the middle square of the cell, y 5 to 15. Draw it in a cell
# s wide and 2 s tall and keep rows s/2 to 3s/2 - 1: a square of s pixels.
#
# No code point is assigned to the mark. U+100000, the first scalar of
# Supplementary Private Use Area-B, which no Nerd Font uses, is the
# scalar its net is trained and drawn at.
