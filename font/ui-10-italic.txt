# Neuronte italic desktop face at an em of 10 pixels: printable ASCII and the
# ellipsis, as pixels. Written for this project. No font was read, and no width
# was copied. The regular face at this em is sheared on the grid, each row by
# (baseline - row) / 4 rounded to the nearest pixel, a tie away from zero, so
# the top sits to the right of the bottom. The advance is widened so the slant
# fits in the row. One character per block: the character (or U+XXXX), a space
# and its advance in pixels, then 10 rows from the ascender down, each starting
# at the pen. # is ink. train/glyphs.py joins each inked pixel to its inked
# neighbours with pen strokes one pixel wide, so the net's target is these
# pixels with round ends. The baseline is row 7 and the x-height row 3. The
# strokes are one pixel wide. Bold is the same letter struck twice, one pixel
# apart, by the drawer.
