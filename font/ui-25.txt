# ellipsis, as pixels. Written for this project. No font was read, and no
# width was copied. One character per block: the character (or U+XXXX), a
# space and its advance in pixels, then 25 rows from the ascender down,
# each starting at the pen. # is ink. train/glyphs.py makes each inked
# pixel a round dot joined to the inked pixel beside it and below, so the
# net's target is these pixels. The baseline is row 19 and the x-height
# row 8; in the drawn cell the baseline is row 33 below the pen
# (UI_TOP 14). The strokes of the nearest pixel face were refitted to
# this grid, two pixels wide. Bold is the same letter struck twice, one pixel apart,
# by the drawer.
