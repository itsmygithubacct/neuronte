# The symbols Kilix prints on its bars, for neuronte-kilix-chrome-v2: the
# same code points as neuronte-kilix-chrome-v1 and the sun and the cloud,
# drawn for the box of two terminal cells that Kilix gives a symbol when a
# blank cell follows it. Written for this project, each from its meaning
# alone. No font was read, and no glyph that another font has at these
# code points was looked at: the private-use code points are the numbers
# Kilix prints and nothing more.
#
# The grid: x 0..18 across the two-cell box, y 0..18 down it, in the syntax
# of strokes.txt (see train/strokes.py). One unit is one pixel when the
# terminal's cell is 9 x 18. A part that starts with "-" is cut out of
# everything before it on the line. train/kilix_chrome2.py puts each
# drawing in the net's cell, twice as tall as wide, and turns each stroke
# into its outline first.
#
# The rules of the drawings: centred in the box both ways; ink inside
# x 1.5..16.5 and y 1.5..16.5, and its straight edges on whole units where
# the shape allows, so they fall on pixel edges at 18 x 18; outlines, thin
# strokes, the gaps between strokes and the marks inside a shape 2 units;
# solid shapes 4 units or more; upright things keep their proportions.
#
# A "# set NAME NETS" line starts a training set: the characters after it,
# in this order, are cut into NETS equal runs, one group net each. A
# character line with no strokes is made by train/kilix_chrome2.py (the
# battery from its level or mark, a weather symbol from a sun, a cloud and
# what falls from it, the bell from neuronte-kilix-chrome-v1's one-cell
# drawing). A "# note U+XXXX text" line says what the symbol means in
# Kilix; the review sheet prints it.
