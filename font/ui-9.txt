# Neuronte desktop face at an em of 9 pixels: printable ASCII and the
# ellipsis, as pixels. Written for this project. No font was read, and no
# width was copied. One character per block: the character (or U+XXXX), a
# space and its advance in pixels, then 9 rows from the ascender down,
# each starting at the pen. # is ink. train/glyphs.py joins each inked
# pixel to its inked neighbours with pen strokes one pixel wide, so the
# net's target is these pixels with round ends. The baseline is row 6
# and the x-height row 3; in the drawn cell the baseline is row 12 below
# the pen (UI_TOP 6). Bold is the same letter struck twice, one pixel
# apart, by the drawer.
