# Neuronte icons, in colour layers. Written for this project; no icon font
# was read or traced. Same grid and shapes as symbols.txt (see
# train/strokes.py). Each line is one character's layers, back to front,
# separated by " || ". A layer starts with its palette entry in braces,
# from font/palette.txt: {fg} is the cell's foreground colour, {clear}
# takes away the layers below it. A layer is one colour at one depth, and
# a lower layer runs under the one above wherever they meet, so no seam
# shows. Icons sit in the middle of the cell, about y 5 to 15.
#
# Straight edges sit on a grid of 0.625, which is one pixel of a cell 16
# pixels wide, so they land on whole pixels at cells 16, 32 and 48 wide and
# stay sharp there. Strokes are mostly 1.25 wide (P@0.625) with their
# centres on that grid.
#
# Icons whose colour carries no meaning are one {fg} layer, so a theme or
# a widget tints them. Battery level, alert, charging, muted and error
# keep fixed colours.
#
