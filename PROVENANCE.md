# Provenance

Where Neuronte's glyphs, weights and data come from, what was and was not
checked, and what is still open. This is a statement by the project. It
is not legal advice and it has not been audited by a third party.

## Summary

- Every glyph Neuronte draws is trained from a drawing written for this
  project, or generated by this project's own code from Unicode character
  names and properties.
- No font file, icon font, glyph outline, bitmap strike or raster artwork
  is an input to any shipped weight file.
- The only third-party data in the pipeline is the Unicode Character
  Database, version 16.0.0. See
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- The code, the drawings and the weights are MIT, one copyright holder.
  See [Licence scope](#licence-scope).

## Glyph sources

Each source file says in its own header how it was made. The table quotes
or paraphrases those headers; the headers are the record.

| Source | What it holds | How it was made |
|---|---|---|
| `font/strokes.txt` | Printable ASCII as pen strokes | Written for this project. No font was read |
| `font/symbols.txt` | Symbols | Written for this project. No font was read |
| `font/letters.txt` | Latin letters beyond ASCII, Greek, Russian Cyrillic | Written for this project. No font was read |
| `font/marks.txt` | Diacritic marks | Written for this project. No font was read |
| `font/ui-N.txt`, `font/ui-N-italic.txt` | The desktop face, one pixel drawing per em size | Written for this project. No font was read, and no width was copied. The italics are the regular face sheared on its own grid |
| `font/icons.txt`, `font/palette.txt` | Colour icons | Written for this project; no icon font was read or traced |
| `font/emoji.txt`, `font/emoji-palette.txt`, `font/emoji-manifest.json` | 300 colour emoji | Generated by `train/emoji.py`. No external artwork, font or raster used |
| `font/pointer.txt`, `font/pointer-palette.txt` | The mouse arrow | Original two-polygon drawing |
| `font/flame.txt`, `font/flame-palette.txt` | The Kilix flame mark | Redrawn from three polygons in the Kilix 95 desktop's own source, which belongs to the same project. No icon file was read or traced. See `font/flame.md` |
| `font/octants.txt` | Which cells each octant fills | Made by `train/mosaics.py` from Unicode's `UnicodeData.txt` 16.0.0; the file records the version and SHA-256 |
| `font/code-masks.txt` | 43 parity masks for the code-point input | Random, from numpy `default_rng(7)`; the header gives the call |

Box drawing, block elements, shades, Braille, sextants and octants have
no drawing file. `train/glyphs.py` builds them from each character's
Unicode name, its dot bits or the cells it fills. Accented letters are a
letter from `strokes.txt` or `letters.txt` plus a mark from `marks.txt`,
placed by Unicode decomposition.

### Code points that follow other projects' conventions

- The icons are trained at the private-use code points where Kilix
  used glyphs from Symbols Nerd Font Mono, so the same characters now
  land on a Neuronte drawing. Only the code-point numbers and each
  icon's meaning are shared. The drawings are this project's own, and no
  Nerd Font glyph was read or traced.
- The flame is trained at U+100000 and the pointer at U+100001, in
  Supplementary Private Use Area-B.

## Training

`train/glyphs.py` turns the sources into signed-distance targets.
`train/train.py` and `train/colour.py` fit a net to them, and
`train/pack.py` writes the `.nrt` file the C library loads.
`train/gate.py` trains the router's gate using Unicode's `Blocks.txt` to
choose which unlabelled code points to sample.

Each weight file stores the arguments it was trained with and the SHA-256
of every source file the trainer read. [TRAINING_MANIFEST.md](TRAINING_MANIFEST.md)
lists them all, and `weights/SHA256SUMS` lists the hash of every file
under `weights/`.

No pretrained model, teacher network or outside dataset is used. Each net
starts from random initialisation and sees only the targets above.

## What has been checked

- `weights/SHA256SUMS` matches every file it lists (297 files) at the
  commit that added this document.
- No font file (`.ttf`, `.otf`, `.woff`, `.woff2`, `.pcf`, `.bdf`, `.psf`,
  `.ttc`, `.fon`) has ever been added in this repository's history, on
  any branch.
- No training, tool or test script opens a font file or calls a font
  rasteriser. Pillow is imported only to read and write images.
- `make test` checks the hashes of the shipped models and compares the C
  library with an independent numpy evaluation.

## Reporting a concern

If a glyph, icon or emoji here appears to copy an existing work, open an
issue on the repository with the code point, the size and the work it
resembles.
